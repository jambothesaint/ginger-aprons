# Ginger — Aprons with a little spice

A responsive, single-page website for an independent apron business concept.

## View the website

Current private preview: https://ginger-aprons.jimmysigns.chatgpt.site

Download the files together and open `index.html` in a browser for a local preview. No installation or build step is needed.

## Files

- `index.html` — page content and layout
- `style.css` — brand styling and responsive layouts
- `app.js` — interactive apron concept selection
- `ginger-kitchen.png` — AI-generated concept photograph

The three apron styles and fabric swatches are illustrative starting concepts, not confirmed products. Replace the sample photograph and copy with actual products before launching a shop. There is no checkout, payment processing or order collection.

This repository stores the website source. GitHub Pages has not been enabled. Changes here do not automatically update the existing Sites preview.
